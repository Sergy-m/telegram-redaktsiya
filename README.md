# Редакция Telegram-канала на одного

Универсальная редакция для блогера. Навык превращает ИИ-ассистента (Claude, ChatGPT) в вашу редакцию. Подходит и тем, у кого канал уже есть, и тем, кто только хочет начать и не знает, о чём писать и где брать материал. Он помогает найти тему, собрать банк идей, разбирает голос канала на правила (паспорт Tone of Voice), проверяет тексты как редактор, сверяет факты перед публикацией, каждое утро собирает черновики постов и раз в неделю разбирает статистику.

Работает на любой теме и в любом формате (по умолчанию Telegram, но подходит и для блога, VK, Дзен, vc.ru, Threads, Instagram, YouTube): недвижимость, кулинария, финансы, спорт, образование, личный бренд. В навыке нет ничьих источников и ничьего голоса. Всё своё вы заполняете сами, а Claude ведёт вас по шагам.

Методика из выступления «Медиахолдинг на одного» (Research Mastermind, 07.10.2026, Сергей Малахов): штат один главный редактор, остальное делают ИИ-агенты, последнее слово всегда за человеком.

## Что внутри

```
telegram-redaktsiya/SKILL.md        сам навык (меню, 14 команд, шаблон Паспорта канала)
telegram-redaktsiya/guides/         две пошаговые инструкции: как завести канал и как превратить его в редакцию на автомате
telegram-redaktsiya.zip             то же самое в виде архива для загрузки в Claude
ИНСТРУКЦИЯ_для_новичка.md           пошаговая инструкция «с нуля»
examples/                           примеры: канал про еду (паспорта) и старт с нуля (тема, банк идей)
LICENSE                             MIT, можно использовать и менять свободно
```

## Быстрый старт (5 минут)

1. Скачайте `telegram-redaktsiya.zip`.
2. В Claude откройте настройки, раздел навыков (названия пунктов могут отличаться в вашей версии), загрузите архив и включите навык. Если такого раздела нет, создайте Проект и вставьте текст из `SKILL.md` в инструкцию проекта, или просто прикрепите `SKILL.md` к чату.
3. Напишите «меню» или «старт»: навык покажет, что вам нужно (канал есть / хочу завести канал / нет идей и материала / что делать дальше / редакция на автомате). Либо выберите сценарий сами:
   - **Канал уже есть.** Напишите **«Настроить редакцию»**, затем пришлите 15-30 своих лучших постов и напишите **«Составь паспорт ToV»**.
   - **Канала нет, тема понятна.** Напишите **«Новый канал»**.
   - **Хочу вести канал, но не знаю о чём писать.** Напишите **«Найти тему»**, затем **«Где брать материал»**: получите тему, пробный пост и банк идей на 30 дней.
4. Дальше ассистент ведёт вас по шагам.
5. Сохраните оба документа в проект или в файл и прикладывайте к новым чатам. Навык сам ваши данные не запоминает.

Дальше каждый день: «Собери посты на сегодня», «Проверь редактором», «Проверено редакцией». Подробности в инструкции для новичка.

## Команды

| Команда | Что делает |
|---|---|
| Меню / Старт | Показывает варианты: есть канал, хочу завести, нет идей, что дальше, автоматизация |
| Завести канал | Пошаговая инструкция: создание канала в Telegram, комментарии, закреп, первые посты, тестовый канал |
| Что дальше | Определяет ваш этап и даёт три следующих шага |
| Редакция на автомате | Лесенка автоматизации: утренние черновики, бот-публикатор, проверка выхода, комментарии, разбор недели |
| Найти тему | Для тех, у кого темы ещё нет: интервью, три круга, проверка тем, позиционирование, пробный пост |
| Где брать материал | Источники материала для рубрик и банк идей на 30 дней |
| Настроить редакцию | Интервью про канал, на выходе Паспорт канала |
| Составь паспорт ToV | Разбор вашего голоса по 7 блокам и готовый промпт для письма в этом голосе |
| Проверь редактором | Редакторский разбор текста с оценками от 🔴 до 🔵 |
| Проверено редакцией | Проверка перед публикацией: факты, названия, голос, картинка |
| Из пресс-релиза / из заметки в пост | Превращает релиз или ваши сырые заметки и голосовые в пост, показывает «до и после» |
| Проверь выход | Проверка после публикации: пост вышел, не обрезался, кросспостинг прошёл |
| Собери посты на сегодня | Утренняя редакция: поиск новостей, отбор, черновики на согласование |
| Новый канал | Запуск канала с нуля или перезапуск: позиционирование, рубрики, ритм |
| Разбор недели | Статистика, лучшие часы публикации, доля постов без правок |

## Пример

В папке `examples/` два вымышленных примера: заполненные Паспорт канала и паспорт голоса для канала о домашней кухне, и старт с нуля для человека, который не знал, о чём писать (тема, пробный пост, банк идей). Откройте, чтобы увидеть, что получится на выходе.

## Важно знать

- Claude ничего не публикует без вашего «да».
- Источники вы называете сами. Claude не решает за вас, кому доверять.
- Автоматизацию (утренний запуск, бот-публикатор) включайте не раньше второй недели, когда руками всё отлажено. Часть шагов (задачи по расписанию, бот-публикатор) зависит от вашего инструмента и тарифа: навык честно скажет, на какой ступеньке остановиться.
- Текст навыка на русском. Для другого языка попросите Claude перевести навык и адаптировать правила стиля.

## Авторство и лицензия

Методика проверки текста опирается на подход из книги Максима Ильяхова и Людмилы Сарычевой «Пиши, сокращай»; текст книги в навык не включён. Лицензия MIT: используйте, меняйте, делитесь.
