**Навык для Claude, который превращает нейросеть в редакцию вашего Telegram-канала.** Он разбирает голос канала на правила, проверяет каждую цифру по источникам, собирает утренние черновики и раз в неделю разбирает статистику. Публикует только то, что вы утвердили.

## Зачем это нужно

Если просто попросить нейросеть написать пост, читатели узнают это с первой строчки. Дело не в промпте и не в модели. Нейросеть начинает писать живым человеческим языком, когда сама разберёт архив канала на правила: какие слова канал любит, каких никогда не допускает, как начинает и заканчивает посты.

Этот навык делает именно это, а потом работает как редакция: шеф-редактор, автор, корректор, фактчекер и аналитик в одном лице. Последнее слово всегда за вами.

Навык универсальный: подходит для канала на любую тему. Всё, что касается вашего канала, живёт в Паспорте, который вы заполняете вместе с Claude.

## Как установить

### В приложении Claude (сайт, компьютер)

1. Скачайте архив [**telegram-redaktsiya.zip**](telegram-redaktsiya.zip): откройте файл и нажмите кнопку загрузки справа.
2. Включите выполнение кода: **Settings → Capabilities** (на тарифах Team и Enterprise это делает администратор).
3. Откройте **Customize → Skills**, нажмите **+**, затем **Create skill → Upload a skill** и выберите архив.
4. Готово. Напишите в новом чате: **«Настроить редакцию»**.

### В Claude Code

Скопируйте папку `telegram-redaktsiya` в `~/.claude/skills/` и перезапустите Claude Code.

## С чего начать

1. **«Настроить редакцию»** — 10–15 минут вопросов, на выходе Паспорт канала.
2. Выгрузите историю канала: Telegram Desktop → меню канала → **Экспорт истории** (HTML или JSON). Пришлите файл и скажите **«Составь паспорт ToV»**.
3. Каждое утро: **«Собери посты на сегодня»**. Когда привыкнете, поставьте это задачей по расписанию.
4. По воскресеньям: **«Разбор недели»**.

Не автоматизируйте всё сразу. Порядок такой: руками, потом полуавтомат, потом автомат.

## Главные правила редакции

- Ничего не публикуется без вашего «да».
- Ничего не выдумывается: нет источника — так и написано.
- Ключевая цифра подтверждается двумя независимыми источниками.
- Голос канала важнее вкуса нейросети.
- Ошибка становится правилом: каждый промах записывается, чтобы не повториться.
- Токены ботов и пароли не хранятся в чате и в файлах.
